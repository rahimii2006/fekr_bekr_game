🎮Mastermind Game(Fekr Bekr)
Written by python.

📌About my game:
In this game the computer randomly generate a secret password by 4 different digits between 1 to 6.
The user has just 10 chance to guess and undrestand the password.
After each guess from user the program gives feedback about :
--> Correct digits in correct place.
--> Correct digits in  wrong place.
